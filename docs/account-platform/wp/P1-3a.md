# P1-3a — split `SettingsCenter.tsx` into one module per panel (pure refactor)

## Why
`src/features/settings/SettingsCenter.tsx` is 1633 lines: the modal shell, 15 panels, ~20 modals
and every helper in one file. The next package (P1-3b) turns settings into a workspace pane tab
whose panels load lazily one by one; that needs each panel in its own module first. This package
ONLY moves code. **Behaviour, markup, class names, labels and ARIA stay byte-for-byte the same.**

## Rules for the move
- **Move, don't rewrite.** Each function body is cut and pasted unchanged. The only edits allowed
  inside a moved body are import-driven renames (none are expected). Do not "fix" anything you
  notice — list it under `deviations:` instead. Known and deliberately left alone: `runAsync`
  swallows errors, the 2FA fallback recovery codes at line 796, `postAccountAction` using
  `getActiveJwt` (later packages own those).
- `EMPTY_PAGES` (184) is used by `GeneralPanel` and `PublicPagesPanel`: declare it locally in
  each (`const EMPTY_PAGES: PageEntry[] = [];`). Sharing it would couple two panels that P1-3b
  loads as separate chunks.
- **No panel module imports another panel module.** Panels import only from `ui/`, `model/`,
  their own folder, and the same app/kit modules `SettingsCenter.tsx` imports today.
- **`memberRows`** (the `useMemo` in the shell, today passed to `PeoplePanel` as `fallbackRows`)
  moves into `PeoplePanel`, computed from the `personas` prop it already receives; drop the
  `fallbackRows` prop. `MemberAccess` and `Avatar` usage inside it is unchanged.
- Each module exports exactly the names other modules import (named exports, no default export,
  no barrel `index.ts`). Keep `SettingsCenter` exported from `SettingsCenter.tsx` with the same
  props — `LazySettingsCenter.tsx` and every caller keep working untouched.
- Imports: each file imports only what it uses (eslint `--max-warnings=0` fails on an unused one).
  Keep the comment at `SettingsCenter.tsx:14-16` (dynamic jszip/i18next/pdf-lib/qrcode imports)
  in whichever files still contain those dynamic imports.
- Every new file gets the 42 header block in the format of `SettingsCenter.tsx:1-11`
  (`By: dlesieur <dlesieur@student.42.fr>`, `Created: 2026/10/22 00:00:00 by dlesieur`,
  `Updated: 2026/10/22 00:00:00 by dlesieur`, the file name in the header). Keep the existing header
  of `SettingsCenter.tsx` and only bump its `Updated:` line.
- Every new file ≤ 300 lines. `SettingsCenter.tsx` ends ≤ 300 lines.
- TypeScript strict, 2-space indent, single quotes — as in the file today.
