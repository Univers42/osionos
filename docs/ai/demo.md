# The AI demo, module by module

The evaluator's script for the A7 dry run, in order. Every step is copied from
the "What an evaluator does in three minutes" section of the module's sheet.
Where the dry run names something the sheet does not document, the text says
**not in the sheet** rather than inventing a step. The marks **UNVERIFIED**,
**UNMEASURED**, **SYNTHETIC**, **TO MEASURE** and **SKIP** are the sheet's own.

## Before the evaluation

Start from the groot worktree. The app is <https://localhost:3001>, the AI
service is <https://localhost:4000>, and the ai-dev stack is
<https://localhost:13001>.

**Compose profiles and flags.**

- M2 and M5: `docker compose --profile ai up -d --build`.
- M1: `OSIONOS_AI_IMAGES=on docker compose --profile ai --profile ai-gpu-vulkan up -d`.
- M7: `docker compose --profile ai --profile ai-vlm up -d`.
- M6: the isolated ai-dev eval stack, with `OSIONOS_SENTIMENT_URL` set and the
  sentiment migration applied.
- M3: `OSIONOS_RECS_FOR_YOU=1` on the bridge.
- M4: on the isolated ai-dev stack, `OSIONOS_MODERATION_ACTIONS=hold` and
  `OSIONOS_MODERATION_STATE=1`, after the moderation migration.
- M1 client: open the app with `?osio.ai.images=1` (or build with
  `VITE_OSIO_AI_IMAGES=1`).

**Seed and demo data.**

- M1: the diffusion model and VAE in `osionos_sd_models` (fetch command in the
  M1 steps); the text encoder is the chat model's cached Qwen3-4B file in
  `osionos_ai_models_llm`.
- M2: a demo workspace with pages to cite; optionally the 110k wiki corpus
  (≈ 55 min of embedding, command in `services/osionos-ai/eval/wiki/README.md`
  "Run it" step 3).
- M3: a few likes, comments and shares (explicit capture, default on); a
  nightly model needs at least 20 users.
- M4: a public page or post, an admin account, and the moderation migration.
- M5: the STT model in its named volume (fetch command in the M5 steps).
- M6: 5 distinct authors and 5 comments on one page, plus the eval-only SQL
  that moves the thread into the past.
- M7: the VLM files in `osionos_ai_a1_data` (`fetch.py --only vlm` of the A1
  spike), and one uploaded png, jpeg or webp.

## 1. M2 — Complete RAG on a large dataset (Major, 2)

Sheet: [modules/m2-rag.md](modules/m2-rag.md). Confidence A.

1. Open <https://localhost:13001> and open the Assistant on the demo workspace.
2. Ask a question that the workspace's pages answer.
3. Read the answer with its `[n]` markers and citation chips.
4. Click a chip: the page opens and scrolls to the block
   (`src/features/chat/model/openCitation.ts:25`,
   `src/widgets/chat-shell/ui/ChatThread.tsx:61`).
5. Read `services/osionos-ai/eval/wiki/RESULTS-rag.md`: variant 1 (hybrid),
   variant 2 (hybrid + rerank), variant 3 (abstention), and the decision line.
6. Optional, not a 3-minute step: rebuild the corpus (≈ 55 min of embedding;
   command in `services/osionos-ai/eval/wiki/README.md` "Run it" step 3).
   **UNVERIFIED on the eval stack**: the 110k corpus lives on a throwaway stack.

The streamed answer, the dropped connection that resumes, and the rate limit
shown are **not in the sheet**; the M2 sheet documents the citation flow only.

## 2. M1 — Complete LLM system interface (text + images) (Major, 2)

Sheet: [modules/m1-images.md](modules/m1-images.md). Confidence B.

1. Before the first start, pre-fetch the diffusion model and VAE into
   `osionos_sd_models` with the `curlimages/curl:8.11.1` command in the sheet
   ("What an evaluator does", step 1). This is the only step with egress; the
   text encoder is the chat model's cached Qwen3-4B file.
2. Start the stack with `OSIONOS_AI_IMAGES=on docker compose --profile ai --profile ai-gpu-vulkan up -d`.
   If `/dev/dri` needs it, set `OSIONOS_AI_SD_RENDER_GID` /
   `OSIONOS_AI_SD_VIDEO_GID` from `stat -c %g /dev/dri/renderD128`.
3. Open the app with `?osio.ai.images=1` (the client flag is off by default).
4. Type `/imagine a lighthouse at dusk` in the editor's slash menu and press
   Enter.
5. See the placeholder "Generating image…" with a Stop button.
6. See the 512×512 image with the caption "AI-generated" (hover: "Generated by
   z-image-turbo"). The output check's recall is **UNMEASURED** (C73).
7. Reload: the caption stays. The stored file carries no prompt (C77).

The streamed answer, the dropped connection that resumes, and the rate limit
shown are **not in the sheet**. The sheet does name the rate limit (C75: the
fourth image of a minute is refused with a Retry-After) and its caveat that the
editor's countdown is a static number of seconds.

## 3. M4 — Content moderation AI (Minor, 1)

Sheet: [modules/m4-moderation.md](modules/m4-moderation.md). Confidence B.

1. On a public page or post, write a comment containing a word from
   `scripts/moderation-lists/en.txt` (for example `acrotomophilia`, line 3).
   The bridge answers 409 `moderation_warning` and writes nothing; the author
   sees the notice (`src/shared/moderation/ModerationWarningNotice.tsx`).
2. Confirm the notice. The comment is written, and the gate records one `l0`
   row with the action `warn`; the trigger enqueues a `moderate` job; the
   worker (`osionos-ai-jobs`) asks the tox TEI and writes one `l1` row. In
   `log` mode that row says what the worker would do, and the comment stays
   visible. The totals of a full run are **not recorded** in the sheet.
3. Read the audit in `public.ai_moderation_events` with the SQL in the sheet
   (`subject_kind = 'page_comment'` or `'feed_comment'`,
   `subject_id = '<the comment id>'`). Expected: an `l0` row (`warn`) then an
   `l1` row (`allow`, or `hold` as the would-be action with `mode = 'log'`).
4. Open Admin space › Moderation queue (`ModerationQueue.tsx`, admin only). The
   queue lists held comments and open reports, not every scored comment; a
   comment scored in `log` mode is in the SQL above.
5. To see one in the console, post a comment with more than five links on a
   public page (L0 holds it), or file a report.
6. Open an item: a `view` row is written first (C92).

L1 is log-only and there is no auto-removal (C83); a human decides, always.

## 4. M5 — Voice / speech (Minor, 1)

Sheet: [modules/m5-voice.md](modules/m5-voice.md). Confidence A.

1. Before the first start, pre-fetch the model with the `docker compose
   --profile ai run --rm --no-deps osionos-ai-stt python -c ...` command in
   the sheet ("What an evaluator does", step 0). The speech-to-text server
   itself never reaches the internet (`HF_HUB_OFFLINE=1`).
2. Start the stack with `docker compose --profile ai up -d --build`; open
   <https://localhost:3001>, with the AI service behind
   <https://localhost:4000>.
3. Click the microphone of the composer (the assistant's, or the channel's —
   the channel's has an accent ring so the two are told apart).
4. Say a sentence.
5. Press the button again, or wait for the 30 s cap: the ring pulses and the
   seconds left are written next to it.
6. See the text land in the box, where the caret was; nothing is sent, nothing
   is approved.
7. Open an answer of the assistant and press "Read aloud"; the voice is one of
   the device's own. In Settings › Accessibility & voice, set the dictation
   language, the voice, its rate, and the opt-in of the online voices. The
   voices are **TO MEASURE** on this host (the sheet's table: Chrome on this
   Linux host has 0).
8. Press `Ctrl+Shift+D` (`Cmd+Shift+D` on a mac) to toggle the dictation of the
   composer that holds the caret, and of no other one.

## 5. M6 — Sentiment analysis (Minor, 1)

Sheet: [modules/m6-sentiment.md](modules/m6-sentiment.md). Confidence C.

1. Settings › AI, section "Sentiment", as an owner or admin of the workspace:
   turn the switch on. A member who is not an owner or admin sees "Only a
   workspace owner or admin can change this."
2. Post comments on one page from 5 accounts (a Pulse week needs 5 distinct
   authors).
3. Eval stack only: after the 5 comments exist and the worker has scored them,
   run the SQL that moves the thread into the past (`update
   public.osionos_page_comments set created_at = date_trunc('week', now()) -
   interval '3 days' where page_id = '<the page id>'`). Never run it anywhere
   else.
4. Reload Settings › AI: one bar for last week, split by tone. With 4 authors
   the week is absent, not zero; the same numbers sit in a visually hidden
   table for screen readers.
5. Open the comment thread of that page (the speech-bubble button of the page
   header). The top line reads "Thread mood: Mostly positive (72 %)" (the real
   words and share depend on the comments). **UNMEASURED on osionos text**: the
   model's 0.70–0.72 is a public multilingual set, not our data.
6. Hover the line: it says the number is an aggregate of at least 5 people.
   With 4 authors there is no line.
7. Switch it off: every score of the workspace is deleted in the same
   transaction (C143); the Pulse and the thread line are gone.

## 6. M7 — Image recognition and tagging (Minor, 1)

Sheet: [modules/m7-images-tags.md](modules/m7-images-tags.md). Confidence C.

1. Start the groot worktree with `--profile ai --profile ai-vlm`, with the VLM
   files in `osionos_ai_a1_data` (`fetch.py --only vlm` of the A1 spike, six
   artifacts, sha256 checked, `RESULTS.md:137`).
2. On a page, upload a picture (png, jpeg or webp). The action exists only for
   uploaded media, an image whose `content` is a `/api/media/uploads/...` path.
3. Hover the image: the toolbar button "Describe with AI"
   (`ImageHoverToolbar.tsx:128`), or the same entry in the block's More menu
   (`imageBlockMenu.tsx:115`, "Describing…" while it runs). A CPU describe
   takes about 12 s, so wait for it.
4. Read and edit: the caption becomes the alt text when the block has none; if
   it has one, "Replace alt text" / "Keep mine". Tags appear as chips; remove
   one with `aria-label="Remove tag <t>"`, add one with the "Add tag" input
   (Enter). The text found in the image is behind a `<details>` disclosure. A
   published page shows the chips without controls.
5. One `updateBlock` call writes `mediaAlt`, `mediaTags` (at most 10, user tags
   first) and `mediaText`.
6. Find it by a word of its caption: the indexer writes `Image: <alt>`,
   `Tags: a, b` and `Text in image: <text>` into the page text, and never the
   capability path (`services/osionos-ai/src/indexer/sections.ts:62-73`).
   **UNVERIFIED in the app**: proved at the chunk level only; no test or run
   shows a page search box finding the image by a caption word, and the
   browser flow itself was not exercised (PR #97 body).
7. Describe the same bytes a second time: it is a cache hit, one VLM call in
   total (`mediaDescribe.test.ts`).

## 7. M3 — ML recommendation system (Major, 2)

Sheet: [modules/m3-recs.md](modules/m3-recs.md). Confidence B.

1. Settings › Privacy: two toggles, a download and a clear. "Use my activity for
   suggestions" (`capture_explicit`, default on) covers likes, comments and the
   like. "Use the pages I see and open to improve recommendations"
   (`beacon_consent`, default off) covers views, impressions and clicks.
   "Download my activity" and "Clear my activity" are next to them (the clear
   needs a second click).
2. With `OSIONOS_RECS_FOR_YOU=1` on the bridge, open the Home tab: a "For you"
   strip. Each card has a "why" and a "Not interested" button.
3. A user who opted out, has no history, or sees no model gets no strip
   (Caveat).
4. Admin space › "Recs health": nDCG@10 of each trained model over time, and the
   daily click-through, with real and synthetic counted apart.
5. The model and its numbers, no stack needed: run the pure test suite
   (40 passed, 13 **SKIPPED**) and the simulated evaluation (iALS 0.1154 nDCG@10
   against popularity 0.0775). Every number from the simulation is
   **SYNTHETIC**.
6. The bridge side, no stack needed: run the `node --test` command in the sheet
   ("What an evaluator does", step 2): 106 passed, 0 failed.
7. The nightly job is expected to **SKIP** with `insufficient_data` under 20
   users; the lead recorded the skip live on 2026-10-23, and this sheet does
   not reproduce it.

"For you" changing after a few likes is **not in the sheet's evaluator steps**.
The mechanism is the online fold-in, which moves the user's vector without
retraining (`osml/foldin.py:43`, `scripts/bridge-recs-model.mjs:176`); the
sheet gives no UI step for it.
