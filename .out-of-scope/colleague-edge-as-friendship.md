# Colleague edge as friendship — out of scope

- Decided: 2026-10-28 · by share-p1 verdict (user ruling U6)
- Holds while: F1 uses manual connections only

## The concept

Treat auto-created colleague edges as friendship for invite gating.

## Why not

- Colleague edges are auto-created as accepted by any members INSERT
  (including public self-join), so counting them launders permanence.
- Friendship must be a deliberate manual accepted connection (source='manual').

## Reopen when

Product explicitly rules otherwise with its own security review.
